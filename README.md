## Research & Engineering Highlights

### Materials Modelling — NIMS, Japan

* Developed a four-block CNN for image-based tensile-strength prediction.
* Achieved **R² = 0.9984** and **2.41 MPa cross-validation RMSE**.
* Extracted **136 image descriptors** using FFT, I-HOG, granulometry, and Minkowski analysis.
* Applied Bayesian spike-and-slab MCMC feature selection using posterior inclusion probabilities.
* Built a six-descriptor Gaussian Process model competitive with the CNN benchmark.
* Submitted the work as a **first-author manuscript to STAM Methods**.

### Wafer Defect Inspection

* Developed an AutoEncoder–CNN pipeline for automated wafer-defect detection and pattern classification.
* Achieved **98% classification accuracy** and **93% precision**.
* Improved robustness using noise augmentation and Bayesian hyperparameter optimisation.

### Optical Metamaterials

* Built a Transfer Matrix Method solver for a **≤ 2 µm TiO₂/SiO₂ Bragg-reflector stack**.
* Obtained approximately **97% solar reflectance** and **75% emissivity** in the 8–13 µm atmospheric window.
* Benchmarked PSO, genetic algorithms, Taguchi optimisation, and Needle optimisation.
* Developed an OptoGPT-based conditional autoregressive transformer for multilayer inverse design.

### Autonomous Vision — ARTPARK, IISc

* Implemented a real-time **720p/30-FPS UAV vision pipeline** using MediaMTX, GStreamer, and OpenCV.
* Integrated object detection, GOTURN tracking, Kalman filtering, and MAVLink telemetry.
* Achieved **98.7% telemetry transmission reliability** with approximately **220 ± 30 ms latency**.
* Contributed to a DO-178C-aligned software-development workflow for autonomous systems.

## Selected Projects

### PatternFlow — Computational Lithography and Mask Optimisation

GPU-accelerated lithography simulation, aerial-image generation, resist-contour prediction, focus-dose modelling, and gradient-based mask optimisation.

**Technologies:** PyTorch · TorchLitho · Abbe/Hopkins Imaging · OPC · Neural Surrogates

### EtchScope — Feature-Scale Plasma-Etch Digital Twin

Automated process sweeps across particle flux, ion energy, selectivity, process time, and feature geometry, followed by surrogate-assisted recipe optimisation.

**Technologies:** ViennaPS · AutoEncoders · Radial Basis Functions · Bayesian Optimisation

### Wafer Defect Detection

Automated multi-class classification of semiconductor wafer-map defects using representation learning and convolutional neural networks.

**Technologies:** Python · TensorFlow/Keras · AutoEncoders · CNNs · Bayesian Optimisation

### Gaussian-Beam Optical Communication and Laser Projector

Modelled Gaussian-beam propagation, designed a 1.55 µm inter-satellite optical link, and generated target optical intensity patterns through plane-wave superposition.

**Technologies:** MATLAB · Gaussian Optics · Fourier Optics · Link-Budget Analysis

### CFD and Heat-Flow Solvers

Developed numerical solvers for variable-area fins, one- and two-dimensional heat conduction, and backward-facing-step flow.

**Methods:** FDM · TDMA · FTCS · Line SOR–GS · Streamfunction–Vorticity Formulation

### Camera Mount for Semiconductor Metrology

Designed multiple FreeCAD cover-plate configurations and prepared manufacturing drawings using third-angle projections, sectional views, threaded features, and ASME Y14.2/Y14.5 conventions.

**Technologies:** FreeCAD · STEP Models · GD&T · Engineering Drawings
